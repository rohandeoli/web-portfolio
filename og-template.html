How to capture this as a 1200×630 PNG:

Fastest (Chrome DevTools, recommended):

1. Open this file in Chrome. 2. Cmd+Opt+I to open DevTools. 3. Cmd+Shift+P → type "screenshot" → choose "Capture node screenshot". 4. Click the .card element in the Elements panel first so it's selected, then run the command. Saves a pixel-perfect 1200×630 PNG.

Alternative (headless Chrome):

chrome --headless --screenshot=og.png --window-size=1200,630 file://$(pwd)/og-template.html — but this captures the page including the help bar, so use the DevTools method instead.
